# 项目报告存储目录

此目录用于存放系统生成的项目报告PDF文件。

## 目录说明

- 本目录 `backend/uploads/progress_reports/` 是专门用于存放项目报告PDF文件的目录
- 系统会自动在此目录中生成带时间戳的PDF报告文件
- 文件命名格式：`项目报告_YYYYMMDD_HHMMSS.pdf`

## 功能特点

1. **自动生成**：系统管理员可以在后台管理页面点击"生成项目报告"按钮自动生成PDF报告
2. **在线预览**：支持在浏览器中直接预览PDF文件
3. **下载功能**：可以直接下载PDF报告到本地
4. **报告管理**：支持查看报告列表、删除过期报告等功能

## 报告内容

项目报告包含以下内容：
- 系统概览（用户总数、任务总数、设备总数）
- 任务状态统计（待处理、进行中、已完成、失败）
- 设备状态统计（在线、离线）
- 生成时间和生成用户信息

## 访问方式

1. **后台管理访问**：
   - 登录系统后台
   - 进入"系统设置"页面
   - 点击"生成项目报告"或"查看报告列表"

2. **直接URL访问**：
   - `http://localhost:8000/uploads/progress_reports/项目报告_20241201_143000.pdf`

## 技术实现

- 后端使用 ReportLab 库生成PDF文件
- 前端使用 Element Plus 提供用户界面
- 支持文件预览、下载、删除等操作
