# 在线聊天系统 - 快速开始指南

## 🚀 5分钟快速上手

### 1. 启动后端服务

```bash
cd backend
python main.py
```

服务启动后会看到：
```
✅ Redis连接成功
✅ 创建默认聊天室成功
✅ 上传目录初始化完成
🚀 多智能体协作运维系统 已启动
📖 API文档: http://localhost:8000/docs
💬 聊天API: http://localhost:8000/api/chat
```

### 2. 快速测试API

#### 获取JWT Token（用于认证）
首先需要登录获取token：
```bash
curl -X POST "http://localhost:8000/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"your_username","password":"your_password"}'
```

#### 发送第一条消息
```bash
curl -X POST "http://localhost:8000/api/chat/send" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"message_type":"text","content":"Hello, World!"}'
```

#### 获取消息历史
```bash
curl -X GET "http://localhost:8000/api/chat/messages" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

#### 查看在线用户
```bash
curl -X GET "http://localhost:8000/api/chat/online-users" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 3. 文件上传测试

```bash
curl -X POST "http://localhost:8000/api/chat/upload" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "file=@/path/to/your/file.jpg" \
  -F "room_id=global"
```

## 📱 前端集成示例

### HTML + JavaScript 简单示例

```html
<!DOCTYPE html>
<html>
<head>
    <title>聊天系统测试</title>
    <style>
        .chat-container { max-width: 800px; margin: 0 auto; padding: 20px; }
        .messages { height: 400px; overflow-y: auto; border: 1px solid #ccc; padding: 10px; margin-bottom: 10px; }
        .message { margin-bottom: 10px; }
        .input-group { display: flex; gap: 10px; }
        .input-group input { flex: 1; padding: 10px; }
        .input-group button { padding: 10px 20px; }
        .online-users { margin-top: 20px; padding: 10px; background: #f5f5f5; }
    </style>
</head>
<body>
    <div class="chat-container">
        <div id="messages" class="messages"></div>
        <div class="input-group">
            <input type="text" id="messageInput" placeholder="输入消息..." onkeypress="handleKeyPress(event)">
            <button onclick="sendMessage()">发送</button>
            <input type="file" id="fileInput" onchange="uploadFile()">
        </div>
        <div id="onlineUsers" class="online-users"></div>
    </div>

    <script>
        const API_BASE = 'http://localhost:8000';
        const TOKEN = 'YOUR_JWT_TOKEN'; // 替换为实际的JWT Token

        // 发送消息
        async function sendMessage() {
            const input = document.getElementById('messageInput');
            const content = input.value.trim();
            if (!content) return;

            try {
                const response = await fetch(`${API_BASE}/api/chat/send`, {
                    method: 'POST',
                    headers: {
                        'Authorization': `Bearer ${TOKEN}`,
                        'Content-Type': 'application/json'
                    },
                    body: JSON.stringify({
                        message_type: 'text',
                        content: content
                    })
                });
                
                if (response.ok) {
                    input.value = '';
                    loadMessages();
                }
            } catch (error) {
                console.error('发送消息失败:', error);
            }
        }

        // 加载消息
        async function loadMessages() {
            try {
                const response = await fetch(`${API_BASE}/api/chat/messages`, {
                    headers: { 'Authorization': `Bearer ${TOKEN}` }
                });
                
                const messages = await response.json();
                const messagesDiv = document.getElementById('messages');
                messagesDiv.innerHTML = messages.reverse().map(msg => `
                    <div class="message">
                        <strong>${msg.sender_name}:</strong> 
                        ${msg.message_type === 'image' || msg.message_type === 'file' ? 
                          `<a href="${msg.file_url}" target="_blank">${msg.content}</a>` : 
                          msg.content}
                        <small>(${new Date(msg.timestamp).toLocaleString()})</small>
                    </div>
                `).join('');
                messagesDiv.scrollTop = messagesDiv.scrollHeight;
            } catch (error) {
                console.error('加载消息失败:', error);
            }
        }

        // 上传文件
        async function uploadFile() {
            const fileInput = document.getElementById('fileInput');
            const file = fileInput.files[0];
            if (!file) return;

            const formData = new FormData();
            formData.append('file', file);
            formData.append('room_id', 'global');

            try {
                const response = await fetch(`${API_BASE}/api/chat/upload`, {
                    method: 'POST',
                    headers: { 'Authorization': `Bearer ${TOKEN}` },
                    body: formData
                });

                if (response.ok) {
                    fileInput.value = '';
                    loadMessages();
                }
            } catch (error) {
                console.error('文件上传失败:', error);
            }
        }

        // 加载在线用户
        async function loadOnlineUsers() {
            try {
                const response = await fetch(`${API_BASE}/api/chat/online-users`, {
                    headers: { 'Authorization': `Bearer ${TOKEN}` }
                });
                
                const users = await response.json();
                const usersDiv = document.getElementById('onlineUsers');
                usersDiv.innerHTML = `
                    <h3>在线用户 (${users.length})</h3>
                    ${users.map(user => `
                        <div>${user.username} - ${user.ip}</div>
                    `).join('')}
                `;
            } catch (error) {
                console.error('加载在线用户失败:', error);
            }
        }

        // 心跳检测
        async function heartbeat() {
            try {
                await fetch(`${API_BASE}/api/chat/heartbeat`, {
                    method: 'POST',
                    headers: { 'Authorization': `Bearer ${TOKEN}` }
                });
            } catch (error) {
                console.error('心跳检测失败:', error);
            }
        }

        // 键盘事件处理
        function handleKeyPress(event) {
            if (event.key === 'Enter') {
                sendMessage();
            }
        }

        // 初始化
        document.addEventListener('DOMContentLoaded', function() {
            loadMessages();
            loadOnlineUsers();
            
            // 定时刷新消息和在线用户
            setInterval(loadMessages, 3000);
            setInterval(loadOnlineUsers, 10000);
            setInterval(heartbeat, 30000);
        });
    </script>
</body>
</html>
```

## 🔧 常用操作

### 1. 创建聊天室
```bash
curl -X POST "http://localhost:8000/api/chat/rooms" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "room_name=技术讨论" \
  -F "description=用于技术问题讨论"
```

### 2. 获取聊天统计
```bash
curl -X GET "http://localhost:8000/api/chat/stats" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 3. 查看用户IP
```bash
curl -X GET "http://localhost:8000/api/chat/user-ip/1" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## 🐛 故障排除

### 常见问题

1. **Redis连接失败**
   ```bash
   # 启动Redis服务
   redis-server
   ```

2. **文件上传失败**
   - 检查文件大小是否超过10MB
   - 检查文件类型是否支持
   - 确保uploads目录有写权限

3. **认证失败**
   - 确保JWT Token有效
   - 检查Token是否在请求头中正确设置

4. **消息不显示**
   - 检查聊天室ID是否正确
   - 确保用户已加入聊天室

## 🔐 安全建议

1. **生产环境配置**：
   - 修改默认的SECRET_KEY
   - 配置CORS允许的域名
   - 启用HTTPS

2. **Redis安全**：
   - 设置Redis密码
   - 配置防火墙规则

3. **文件上传安全**：
   - 限制文件类型
   - 扫描上传文件
   - 设置适当的文件权限
